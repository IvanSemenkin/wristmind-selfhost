# WristMind SelfHost 0.2.5 — промпты и надёжное обновление

- Полный основной промпт рабочего WristMind теперь находится в исполняемом коде: графики chart, формулы, информационные блоки и объяснение возможностей доступны новой установке. При обновлении заменяются только прежние заводские короткие промпты; пользовательские тексты и режимы сохраняются.
- Меню 5 → 2 самостоятельно выбирает готовый выпуск для amd64/arm64, скачивает и проверяет его перед обязательным бэкапом и обновлением.
- Исправлено несовпадение config/OCI digest между версиями Docker. Принимается только подтверждённая SHA256 связь в проверенном архиве; архитектура и ОС проверяются по-прежнему.
- Длительные операции показывают меняющийся индикатор и время, скачивание — фактически полученный объём. Ввод с CRLF, пустая строка и неверный пункт больше не выбрасывают из подменю.

Локально проверены новая установка, миграция старых промптов, сохранение пользовательских инструкций, управление меню, архивы и обслуживание. Проверка 0.2.4 выполнена с фактическим image ID тестового сервера. Реальное обновление выполняет пользователь через меню; на серверах при подготовке выпуска ничего не устанавливалось.

Android-компаньон остаётся в отдельном android-v0.2.0-preview.1; этот выпуск обновляет сервер. HTTP по IP не поддерживает микрофон браузера: для него нужен HTTPS.

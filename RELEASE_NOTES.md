# WristMind SelfHost 0.3.1 — стабильный вход и ночные обновления

- Активный вход в панель продлевается: 30 дней с обновлением срока примерно раз в сутки. Рабочая сессия не истекает каждые 12 часов. Выход и отзыв доступа продолжают действовать.
- Повторный вход из того же браузера использует прежнюю запись устройства; разные браузеры остаются разными устройствами. Старые дубликаты не удаляются. Идентификатор браузера подписан и не позволяет войти без пароля.
- Ошибка доступа к внешнему провайдеру и временный сетевой сбой больше не сбрасывают вход в панель; поздняя ошибка старого запроса проверяется по текущей сессии.
- В терминальном меню **5 → 8** доступно ночное автообновление. По умолчанию выключено; при включении выберите время (04:00) и свой часовой пояс. Пропущенный ночной запуск не выполняется днём.
- Автообновление использует обычный проверенный пакет, резервную копию, проверку запуска и откат при ошибке. При обнаружении активных заданий обновление пропускается до следующей ночи. Логи доступны через journalctl.
- После возврата на вкладку веб-чат восстанавливает уже принятый ответ без повторной отправки; отправленный текст больше не возвращается в черновик.

Для обновления откройте свежий установщик и выберите **5 → 2**. После этого при желании включите расписание через **5 → 8**. На тестовый сервер ничего не устанавливается напрямую; обновление выполняет владелец через меню.

Ночное расписание требует systemd и настраивается в терминале; кнопок обновления в веб-панели нет. Смена адреса сайта или очистка cookies создаёт новую браузерную идентичность. Настройки таймера относятся к этому серверу: после восстановления на другой сервер расписание нужно включить заново.

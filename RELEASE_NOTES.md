# WristMind SelfHost 0.3.0 — надёжный и адаптивный веб-поиск

- Полный текст длинных HTML доступен чтению, поиску фрагментов и сохранению рабочего источника.
- Комментарий или пересказ больше не подтверждает оригинал по наличию заголовков глав. Составные запросы продолжают проверку после поиска документа.
- Исправлены сохранение предыдущего результата, обработка JSON планировщика и накопление прочитанных фрагментов.
- Общие адаптивные лимиты учитывают память Linux/cgroup и CPU: сравнение двух источников допускает две параллельные загрузки, тяжёлая обработка остаётся ограниченной.
- Добавлены backpressure, ограничение ожидания ресурсов и безопасное удержание слотов при отмене физических PDF/OCR-потоков.
- Сохранены TTL-кэш, рабочие источники, последующие RAG-вопросы и внешние поисковые API. Расширена диагностика без записи ключей и полных сообщений.
- Сохранены исправления меню обслуживания и отключённой служебной приписки из предыдущих версий.

Обновление: запустите единое меню установки и выберите **5 → 2**. Пакеты: **amd64** и **arm64**, с контрольными суммами. Веб-кнопки обновления нет. APK компаньона не меняется: используйте ранее опубликованный Android-релиз.

Локальные целевые проверки: основной backend 70 passed, SelfHost 59 passed; отдельно актуальные 20 тестов контроллера в обеих копиях. Наборы пересекаются. В малой локальной выборке двух HTML с настоящей trafilatura и имитацией сети p50 591 → 462 ms; это не обещание ускорения живого поиска на сервере.

Выпуск остаётся предварительным (0.x). Чистая установка/обновление на произвольном SelfHost-сервере и реальные часы требуют пользовательской приёмки. Физически зависший PDF/OCR поток удерживает слот до завершения; уже выполняющаяся индексация не прерывается новым ответом. Перед обновлением меню создаёт резервную копию данных.

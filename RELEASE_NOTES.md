# WristMind SelfHost 0.2.2 — предварительный серверный выпуск

Готовые пакеты amd64/arm64 предназначены для проверки установки и обновления через терминальное меню. Android-компаньон остаётся в отдельном android-v0.2.0-preview.1; отдельный APK часов не требуется.

## Исправления

- Создание чатов, отправка сообщений и загрузка источников работают без secure-context метода randomUUID: HTTP по IP больше не ломает запрос до обращения к API.
- Рекомендации мощности не выключают голосовой API и не меняют переключатель внешнего поиска.
- Vision можно настроить независимо от OCR. DeepSeek не предлагается для Vision, STT или embeddings; сервер проверяет ограничения роли.
- Веб-поиск: SearXNG либо Yandex Search API, Brave, Tavily. Ключи хранятся зашифрованно и не выдаются панели.
- Установщик сам готовит зависимости на поддерживаемых Ubuntu/Debian, показывает время и этап сборки, определяет IP и выдаёт полную ссылку первого входа.

## Проверки и ограничения

Локальные тесты API/установщика, веб-тесты и production-сборка пройдены. HTTP UUID проверен при отсутствии randomUUID. Внешние поисковые адаптеры проверены на MockTransport; реальные платные ключи не использовались. Обновление на пользовательском тестовом сервере ещё не выполнено — это следующий шаг приёмки. На сервер dm ничего не устанавливалось.

HTTP не шифрует соединение и не поддерживает микрофон браузера: для веб-диктовки нужен HTTPS. Внешний поисковый API заменяет поиск выдачи, но найденные страницы читает сервер. Наличие пакета и успешные локальные проверки не означают завершённую серверную/часовую приёмку.

Команда веб-тестов совместима с Node 22 в GitHub Actions; неудачный тег v0.2.1 сохранён, пакет по нему не публиковался.

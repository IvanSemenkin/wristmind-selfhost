# WristMind

AI-ассистент на часах Wear OS: голосовой чат, режимы и свои базы знаний.
Ставится на свой сервер, данные остаются у владельца.

> Это публичный первый экран продукта. Текущее состояние self-hosting —
> в [docs/SELF_HOSTING_STATUS.md](docs/SELF_HOSTING_STATUS.md): что уже работает,
> а что ещё в работе. Утверждения ниже сверены с этим файлом.

## Что это

Говорите в часы — получаете ответ. Режимы задают, как ассистент думает: свой
промпт, своя модель, своя база знаний. Веб-панель управляет режимами,
источниками, устройствами и настройками. Сервер ваш: диалоги, документы и ключи
не уходят третьим лицам, кроме выбранного вами провайдера модели.

## Что понадобится

Честный список, до первого клика:

- **часы Wear OS.** Проверено на Xiaomi Watch 2; другие модели Wear OS — по возможности;
- **сервер или VPS:** 2 vCPU, 4 ГБ RAM, 10 ГБ диска;
- **домен.** Без HTTPS часы не подключатся: TLS-сертификат обязателен;
- **ключ провайдера модели:** OpenRouter или DeepSeek. Оплата — на владельце;
- **Wi-Fi,** где телефон и часы в одной сети, на момент установки приложения на часы.

## Чего не нужно

- Google Play;
- аккаунтов в сторонних сервисах;
- VPN;
- ручного `adb` с ноутбука.

## Установка

Понадобятся Docker и Docker Compose v2.

### Посмотреть локально, без сервера

Моки провайдеров, база в приватном томе, без ключей, домена и часов:

```sh
./wristmind install --local
```

### Сервер или VPS

```sh
./wristmind
```

Меню само определяет состояние машины: на чистой предложит установку, на уже
установленной — управление. Установщик генерирует секреты, поднимает контейнеры
и проверяет `/health`. Публичный адрес можно задать сразу:

```sh
./wristmind install --domain=example.com          # адрес для HTTPS
./wristmind install --public-url=http://203.0.113.9
./wristmind install --with-search --with-telegram  # опциональные сервисы
```

Домен и HTTPS:

```sh
./wristmind tls --domain=example.com --email=you@example.com
```

Установщик проверит, что A-запись домена уже указывает на этот сервер, выпустит
сертификат через ACME и переключит сервер на HTTPS. При неверной A-записи он
честно откажется и не изменит установку.

Повторный запуск ничего не ломает и не переустанавливает.

### Подключение панели и часов

Установщик печатает адреса панели и API, а также bootstrap-секрет для первого
подключения панели. Дальше одноразовые коды для часов выпускаются в панели.

**Мастер первого запуска (`/setup`) ещё не реализован:** владелец и первый режим
пока настраиваются в панели вручную. Состояние — в
[docs/SELF_HOSTING_STATUS.md](docs/SELF_HOSTING_STATUS.md).

## Части репозитория

| Каталог | Что это |
| --- | --- |
| `server/` | FastAPI, PostgreSQL/pgvector, worker, RAG, провайдеры моделей |
| `web/` | Веб-панель управления |
| `android/wear/` | Клиент часов Wear OS (основной чат) |
| `android/phone/` | Компаньон: настройка, статус, резервный транспорт |
| `android/core/` | Общий Kotlin-клиент и протокол |
| `android/panel/` | Обёртка панели для установки на телефон |
| `wristmind` | Установщик и меню управления сервером |

Исторические каталоги `watch/` (Zepp OS / Amazfit Bip 6) и `android/app/`
сохранены для справки и не являются активной архитектурой.

# WristMind

Минимальный вертикальный прототип голосового помощника:

- `android/` — приложение для Poco F6: BLE GATT, запись микрофона, HTTP-загрузка;
- `watch/` — мини-приложение Zepp OS для Amazfit Bip 6;
- `server/` — тестовый FastAPI API, принимающий аудио и возвращающий текст;
- `docs/` — протокол и архитектурные решения.

На первом этапе используется микрофон телефона и тестовый ответ сервера. API-ключи,
VPS, распознавание, LLM, RAG, история и TTS подключаются следующими независимыми
адаптерами без изменения протокола часов.

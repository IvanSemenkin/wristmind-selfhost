# Промпты: источник истины и проверка совпадения

Проверено 11 октября 2026.

Основной системный промпт рабочего сервера хранится в `app_settings.global_system_prompt`, а не в Markdown-файле. Его полный публичный текст теперь является стандартом `server/src/wristmind_server/assistant_prompt.py`; документация `docs/ASSISTANT_SYSTEM_PROMPT.md` совпадает с ним. Это включает chart, формулы, информационные блоки и правила объяснения возможностей.

Новая установка получает полный стандарт. При обновлении заменяются только два известных старых заводских текста: минимальный и прежний краткий. Пользовательские изменения общего промпта, переопределения шаблонов и личные режимы сохраняются.

Сравнение основного и self-host исходников с рабочим API и worker:

| Часть | Результат |
| --- | --- |
| Основной промпт | Синхронизирован с фактически сохранённым рабочим текстом |
| Быстрый чат | Совпадает |
| Служебные шаблоны DEFAULT_TEMPLATES | Совпадают; сохранённых переопределений на рабочем сервере нет |
| Классификаторы источников | Код совпадает, но рабочая база содержит более старые формулировки двух классификаторов |
| Пользовательские режимы | Не копируются в публичную установку |

Различия классификаторов касаются определения рабочего материала: актуальный код признаёт конкретный запрошенный цельный текст материалом чата даже без явно названной следующей задачи. Рабочая база требует намерения дальнейшей работы. Эти старые формулировки не перенесены поверх исправленных стандартов; они не определяют построение графиков.

Настоящая база рабочего сервера при этой проверке не изменялась. Применение новых стандартов на тестовом сервере требуется через терминальное обновление. Проверка документации и стандарта, новой установки, миграции старых стандартов и сохранения пользовательского текста находится в `selfhost/tests/test_prompt_defaults.py`.

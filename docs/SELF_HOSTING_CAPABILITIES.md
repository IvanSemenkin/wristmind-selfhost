# Возможности и мощность сервера

Запустите единое меню на сервере и укажите каталог установленной системы:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IvanSemenkin/wristmind-selfhost/main/install.sh)
```

## Настройка без обязательных дополнительных сервисов

Откройте Настройки → Настройка ИИ → Возможности. Подключите сервис ИИ с ключом и выберите модель для ответов. После сохранения подключения панель ведёт к выбору модели. Локальное чтение текста и поиск по словам не требуют отдельной модели. Необязательные улучшения раскрываются отдельно и подключаются на месте за два шага (сервис → модель); возле каждой показано, работает ли она или требует настройки. Провайдеры и полный список добавленных моделей остаются в соседних разделах. Изменения в этом разделе сохраняются автоматически.

Назначения моделей: ответы в чатах, понимание изображений (Vision), распознавание голоса, поиск по смыслу (embeddings). Каталог провайдера не гарантирует поддержку функции: при добавлении выполняется небольшой платный пробный запрос соответствующего типа. Одну модель можно добавить повторно с другим назначением. Голосовые и embedding-модели не попадают в выбор модели для чата.

Удаление провайдера архивирует подключение и его модели, очищает сохранённый ключ и назначения дополнительных функций. Чаты, источники и режимы не удаляются. Провайдер модели по умолчанию или действующего режима защищён: сначала выберите замену. Удаление не отзывает ключ на стороне провайдера.

## Дополнительные возможности

- Веб-поиск требует SearXNG: сервис включается профилем search через терминал, его URL задаётся серверу. Переключатель в панели разрешает использование поиска, но не управляет Docker.
- Оцифровка читает текстовые PDF и печатный текст через OCR. Vision добавляет понимание изображений и сложных страниц. Без Vision обычное чтение текста остаётся доступным.
- Поиск по источникам без embeddings работает по словам. Модель embeddings включает поиск по смыслу. После смены такой модели нужно повторно обработать источники: старые векторы другой размерности не сравниваются, одинаковая размерность не гарантирует совместимость моделей.
- Без модели голоса серверная диктовка недоступна. Часы запускают встроенное распознавание системы, если оно есть на устройстве; веб-панель объясняет, какую модель добавить.

Голос поддерживает Yandex SpeechKit и провайдеры с совместимым OpenAI API `/audio/transcriptions` (например, соответствующие модели OpenAI/Groq). Не каждый провайдер из общего каталога поддерживает этот endpoint; проверка назначения обнаруживает неподдерживаемые модели. SpeechKit сохраняет потоковый путь; совместимые провайдеры получают накопленное WAV-аудио после остановки. Ограничение HTTP-запроса — 18 секунд внутри существующего 20-секундного ожидания завершения. Проверка ключа SpeechKit обращается непосредственно к нему, независимо от уже выбранной голосовой модели.

Переключатели применяются только к пользовательской SelfHost-версии. Они ограничивают новые операции API/worker, сохраняют данные; работа, уже начатая до переключения, может завершиться. Исходная установка сохраняет существующие интеграции. Общие настройки и адаптеры перечислены в selfhost/shared-settings.json.

## Оценка мощности

`wristmind check` и раскрываемая строка «Мощность сервера» показывают CPU, общий/доступный объём RAM, свободный диск и рекомендации для дополнительных функций. Учитываются CPU affinity и ограничения cgroup v2. Оценка рассчитана примерно на одного активного пользователя и не является нагрузочным тестом: сеть, скорость диска, объём документов и одновременные пользователи влияют на результат. Существующие минимальные требования установщика остаются в силе. Применение рекомендаций требует отдельного нажатия и меняет только переключатели.

## Локальная проверка и ограничения

92 selfhost-теста и 11 тестов реестра провайдеров прошли, включая назначение ролей, ограничение функций, безопасное удаление провайдера, PCM/WAV и совместимые HTTP-адаптеры. Проверки используют изолированные SQLite и mock-транспорты, не настоящие платные API. Web typecheck/build прошли; ранее 108 web-тестов и 99 Wear unit-тестов прошли. Дополнительная регрессия сервера: 26 прошли, 2 теста worker упали на `sqlite database is locked`; это не считается успешной серверной приёмкой и требует отдельного разбора. Настоящие провайдеры, PostgreSQL/Docker и физические часы проверяются в финальной приёмке. Проверка встроенного распознавания зависит от устройства. Для компиляции Wear использовалась временная синтетическая debug-конфигурация Firebase, удалённая после проверки; production-конфигурация в копию не переносилась.


## Внешний веб-поиск

В настройках функций выберите способ поиска: локальный SearXNG либо Yandex Search API, Brave Search API, Tavily. Для внешнего сервиса нужен его ключ; для Yandex также ID каталога. Ключ хранится в зашифрованной серверной конфигурации, API панели сообщает только факт его наличия. Переключение не удаляет локальный сервис и не отправляет запрос одновременно нескольким провайдерам. Внешний API не нагружает локальный SearXNG, однако извлечение содержимого найденных страниц выполняется на сервере. Подключение ключа само по себе не делает платный проверочный запрос.

Контракты: [Yandex](https://yandex.cloud/en/docs/search-api/api-ref/WebSearch/search), [Brave](https://api-dashboard.search.brave.com/app/documentation/web-search), [Tavily](https://docs.tavily.com/documentation/api-reference/endpoint/search).

Vision подключается независимо от OCR; API DeepSeek используется для текстовых ответов. Голос через API и внешний поиск сохраняют свои переключатели при применении рекомендаций CPU/RAM. Микрофону веб-браузера по-прежнему нужен HTTPS: HTTP-доступ по IP подходит для текстового общения.

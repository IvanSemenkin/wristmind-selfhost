# Локальная оцифровка, поиск и RAG

Запустите единое меню на сервере и укажите каталог установленной системы:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IvanSemenkin/wristmind-selfhost/main/install.sh)
```

Актуальное ограничение от владельца: локально работают оцифровка PDF/OCR, поиск по словам и RAG. Для улучшения RAG можно установить EmbeddingGemma. Vision, чатовые и голосовые модели этим установщиком не устанавливаются — они подключаются через внешних провайдеров.

Базовое чтение PDF/OCR и поиск по словам уже выполняются на сервере без дополнительной модели. Vision — отдельное необязательное улучшение понимания изображений, а не требование для OCR.

## Одна команда для поиска по смыслу

В терминале сервера, из каталога исходников/релиза WristMind:

**В меню выберите:** 7 «Локальный поиск по смыслу».


Замените каталог установленной системы, если он другой. Скрипт проверяет установку и ресурсы, запрашивает подтверждение загрузки, запускает приватный Ollama, скачивает фиксированную EmbeddingGemma, проверяет настоящие embeddings из API-контейнера и автоматически сохраняет подключение, модель и назначение для RAG. Повторный запуск не дублирует записи. Существующие провайдеры, чаты, текстовая модель по умолчанию и назначения Vision/голоса сохраняются. При неудачной проверке модели назначение не меняется. Ключ, ручной ввод URL и выбор модели не нужны.

После сообщения «Готово» вернитесь в настройки либо обновите панель. Документы, обработанные до подключения embeddings, нужно повторно обработать для поиска по смыслу. В демо установки и inference нет: список моделей/ответы имитируются. Открытие инструкции не запускает команду.

Нужно минимум 4 ГиБ RAM и 6 ГиБ свободного диска. Это ограничение, а не гарантия скорости: CPU и параллельная нагрузка влияют на задержку. Настоящие замеры и Docker/ARM64-приёмка ожидают финального сервера. Для автоматизации после проверки требований можно передать `--yes`.

Ollama включается optional-профилем `local-ai`, не публикует порты, не передаёт Docker socket панели. Внутренний URL `http://ollama:11434/v1` использует сервер, а не телефон. Cloud-функции отключены через `OLLAMA_NO_CLOUD=1`, параллелизм и число загруженных моделей ограничены единицей. Образ по умолчанию `ollama/ollama:latest`; для закрепления используйте `WRISTMIND_OLLAMA_IMAGE`.

Веса хранятся в `local_models` как повторно скачиваемый кеш и не входят в резервную копию пользовательской БД/документов. На новой машине потребуется загрузка весов/образа. Скрипт и модуль автоматического назначения входят в установленный payload/образ нового релиза. Старую установку сначала обновите до релиза с этим модулем.

## Проверки

Проверяются план Compose/pull/автоназначения, запрет установки Vision/голоса/чатовой модели, недостаток ресурсов, приватный профиль без speech-сервиса, повторное назначение без дублей, сохранение других ролей и остановка перед сохранением при неудачном inference. Docker и модель в этих тестах подменены; настоящая серверная установка ещё не проверена.

Источники: [Ollama Docker](https://docs.ollama.com/docker), [OpenAI-compatible API](https://docs.ollama.com/api/openai-compatibility), [EmbeddingGemma](https://ollama.com/library/embeddinggemma).

# Проверка оригинала и сохранение рабочего источника

12 октября 2026.

## Исправленные причины

- Комментарии и пособия могли получать высокий рейтинг по совпадению автора/названия. Их заголовки всех глав затем давали ложный результат проверки полноты. Для запроса оригинала добавлено понижение вторичных материалов и проверка типа по названию/началу документа; такой материал не сохраняется и не подтверждает оригинал.
- Структурная проверка преждевременно завершала составной запрос. Для запроса эпизодов/цитат/анализа агент продолжает работу; при преждевременном ответе планировщика выполняется дополнительное чтение документа. Несколько find/read сохраняют до шести фрагментов в пределах прежнего общего лимита контекста.
- Сохранение найденного текста могло ошибочно наследовать запрет интернета от маршрутизатора. Явная команда сохранения найденного материала корректирует такой маршрут; явный запрет пользователя сохраняет приоритет. Короткая команда разрешается по прошлым запросам пользователя, с сохранением автора, названия и требований полноты; слова ассистента доказательством не являются.
- Отказ проверки сохранения не должен завершать поиск как успешный. Когда нужен рабочий источник, агент продолжает подходящие открытия до реального сохранения или исчерпания бюджета; при исчерпании старых ссылок допускается новый ограниченный поиск.
- Полный HTML при запросе целого оригинала/сохранения больше не заменяется выбранным моделью отрывком. Сохраняются полный извлечённый текст, хеш и диапазон; индексация остаётся отдельным штатным INGEST. Запросы только отрывка сохраняют прежнюю логику.
- Проверка источника принимает корректный JSON в Markdown-блоке. Актуальный протокол планировщика дописывается после пользовательского шаблона; управляющие вызовы DeepSeek идут без thinking.
- Ответ получает явный каталог прочитанных и непрочитанных ссылок и запрет утверждать проверку непрочитанного оригинала/заполнять отсутствующие эпизоды по памяти. При отсутствии рабочих источников сообщение об отказе больше не утверждает, что прежние источники остались.

## Границы

Проверка структуры не доказывает текстологическую подлинность или отсутствие сокращений внутри глав. Эвристики вторичных материалов консервативны; сложные случаи сохраняют модельную проверку. Полный извлечённый HTML может содержать оставшийся после trafilatura служебный текст. Контекст модели ограничен; накопление фрагментов не гарантирует наличие доказательств для каждого подпункта.

API, UI, ограничения загрузки/SSRF, один worker, TTL/квоты кэша, PDF extraction и пользовательские рабочие источники не менялись. Нет удаления данных, миграций и массовой переиндексации. Нет живого нагрузочного теста или нового сетевого бенчмарка. Сохранение полного документа индексируется только при принятии рабочего источника штатным механизмом.

Основной API/worker обновлены, три файла совпадают по хешам с локальными, публичная проверка здоровья успешна. Старая история не переписывалась.

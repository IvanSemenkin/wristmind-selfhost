# BLE-протокол v1

Сервис:

- Service UUID: `8a710001-5f31-4a7c-bc51-6a7c250d6f10`
- Command characteristic (watch → phone, write):
  `8a710002-5f31-4a7c-bc51-6a7c250d6f10`
- Event characteristic (phone → watch, notify/read):
  `8a710003-5f31-4a7c-bc51-6a7c250d6f10`

Кодировка: компактные UTF-8 кадры длиной до 20 байт. Это позволяет работать
без обязательного увеличения BLE MTU. Полный ответ остаётся на телефоне; часы
получают короткий ответ частями.

Команды:

```text
C|42|START
C|43|STOP
C|44|RETRY
C|45|PING
```

`id` используется для дедупликации.

Статусы:

```text
S|IDLE
S|REC
S|STOP
S|SEND
S|PROC
S|READY
E|NETWORK
```

Фрагменты ответа:

```text
A|1|3|Первая часть
A|2|3| второй
A|3|3| части
```

Повтор команды с тем же `id` не повторяет побочный эффект; телефон возвращает
последнее известное состояние.
